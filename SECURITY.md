# Politique de sécurité

## Versions supportées

| Version | Supportée |
|---------|-----------|
| 0.x     | ✅ développement |

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour les failles de sécurité.

Envoie un email à `security@noliae.com` avec :
- Description de la faille
- Étapes pour reproduire
- Impact estimé
- Si tu as un correctif, propose-le

On répond sous **72h** et publie un CVE dès qu'un correctif est dispo (ou 90 jours max sans réponse, embargo levé).

Merci de respecter le principe de divulgation responsable.
